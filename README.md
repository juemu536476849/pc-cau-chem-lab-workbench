# 物化 / 化工实验数据处理工作台

把物理化学、化工原理实验的「原始数据 → 计算 → 图表 → 报告用结果」串成一条线：
选实验、粘贴数据、点运行，得到关键指标、图表，以及一键导出的 **Excel 明细**和 **Word 实验报告**。

> **适用对象**：中国农业大学 **化学专业**本科生课程实验——
> 物理化学实验（A1–A6、A8、B1–B5）与化工基础实验（实验 1–7）。
> 参数、公式与对照值均按本校讲义和本人当年的实验数据还原；
> 换学校、换教材、换仪器，常数与经验式需要相应修改（见「五、自己加一个实验」）。

- 数据只在**本机**处理，不上传、不联网（只有第一次准备环境时需要联网下载 Python）。
- 每个实验都附带从 F 盘归档的**原始数据、历史脚本、实验报告与参考资料**。
- 计算逻辑按当年实验报告与历史脚本还原，关键结果附报告对照值。

---

## 一、怎么开始（真的只有一个动作）

**双击 `启动工作台.bat`。**

- 电脑上没有 Python 也没关系：第一次运行会自动下载一个便携版 Python 和计算库
  （约 90 MB，放在本文件夹的 `runtime\` 里，**不会改动系统环境，不用管理员权限**），
  装好之后浏览器自动打开工作台。
- 之后再打开就很快，直接进入工作台。

打开后只有三步：

1. 左侧选一个实验（数据已经用当年实验的真实数据预填好）。
2. 核对或粘贴自己的数据（在 Excel 里复制，点表格第一格 `Ctrl+V`）。
3. 点 **运行计算**（或 `Ctrl+Enter`）看结果；需要时点 **导出 Excel**（数据明细）或 **导出 Word**（排好版的实验报告）。

> 关闭那个黑色命令行窗口，工作台就退出了。

改参数、改数据后会自动重算，不必每次点按钮。

## 二、界面怎么看

| 区域 | 作用 |
| --- | --- |
| 首页卡片 | 按「物化 / 化工」分组列出全部实验，点一下进入 |
| 左侧栏 | 搜索实验名或编号（如 `A4`、`精馏`）；⌂ 返回首页 |
| 输入列 | **参数**（一般保持默认）+ **数据表**（可直接从 Excel 粘贴）+ **原始资料**（报告/数据文件）+ 计算方法 |
| 结果列 | 一句话结论 + 关键指标卡 + 图表 + 结果表 + 提示与说明 |
| 顶部按钮 | 运行计算（`Ctrl+Enter`）、导出 Excel、导出 Word、复位（恢复示例数据） |

**粘贴数据**：在 Excel 里选中区域复制，点数据表里任意一个单元格（一般点左上角第一格），`Ctrl+V`。
会从这一格开始向右下铺开，行数不够时自动补行。表头不用复制；列顺序按页面显示的顺序。空行/空单元格会自动跳过。

**复制表格**：输入表左下的「复制表格」按钮把整张表（含表头）按 Excel 的制表符格式放进剪贴板，
直接到 Excel 里 `Ctrl+V` 就能得到一格一列的表格；结果表右上角也有「复制」。
（手动框选输入框再 `Ctrl+C` 只能复制到一格，想要整表请用按钮。）

**导入文件**：点数据表右上角「导入文件」，选 `.xlsx / .csv`（CSV 的 UTF-8 和 GBK 编码都支持）。
**有没有表头都能导**：表头上方的标题行、文字表头行、以及 Excel 里自带的「序号」列会自动识别并跳过，
列错位时会按表头自动对齐；导入完成会提示「已导入 N 行 × M 列」，如果某格不是数字会直接点名是第几行哪一列。

**导出 Excel**：把「结果 + 参数 + 当前数据」写进 `outputs/` 目录并下载，适合自己再算。

**导出 Word**：只生成 `.docx` 文件（本工作台不导出 PDF），A4 排版，正文中文宋体、
西文 Times New Roman，**没有页脚、没有图注/表注**，可以直接粘进课程报告模板里。报告内容包括原理与数据处理方法、主要结果表、关系图、
计算结果表、原始数据、计算参数、说明；图直接嵌进文档，不用再截图排版。

- **第一次点「导出 Word」会让你选一个文件夹**（浏览器弹窗），以后报告都自动存进那个文件夹，不再询问。
- 想换地方：按住 `Shift` 再点「导出 Word」，重新选文件夹。
- 如果浏览器不支持选文件夹（极少数旧浏览器），就存到默认下载文件夹。
- 图表右上角「下载 SVG」可单独得到矢量图，需要更高清时用。

## 四、目录结构

```
物化-化工实验脚本/
├─ 启动工作台.bat          双击启动（唯一入口，会自动准备环境）
├─ setup_env.ps1           首次运行时自动下载便携 Python 与依赖
├─ requirements.txt        Python 依赖清单
├─ README.md
├─ app/                    程序本体
│  ├─ server.py            Flask 服务（只监听 127.0.0.1）
│  ├─ registry.py          自动发现 app/modules/*.py
│  ├─ core.py              数值工具（拟合、插值、格式化）
│  ├─ selftest.py          模块自测
│  ├─ contract.md          模块开发契约
│  ├─ modules/             每个实验一个计算模块
│  └─ web/                 前端页面（单页，无 CDN）
├─ data/                   原始资料（按实验分类）
│  ├─ 物化实验/<编号-名称>/{原始数据,原始脚本,实验报告,参考资料,参考图片}
│  └─ 化工实验/<编号-名称>/{原始数据,原始脚本,实验报告,参考图片}
├─ runtime/                首次运行后出现：便携 Python 与依赖（约 250 MB）
└─ outputs/                导出的 Excel
```

## 五、想加一个新实验

1. 在 `app/modules/` 新建 `x1.py`，按 `app/contract.md` 写 `SPEC` 与 `run(data)`。
2. 参考 `app/modules/a1.py`（最简单）或 `c5.py`（图谱类）。
3. 运行 `python -m app.selftest x1`，通过后重启工作台，左侧会自动出现新实验。

模块只需要返回 `kpis / charts / tables / notes / warnings` 五类内容，
前端会自动排版，不需要改 HTML。

## 六、常见问题

- **第一次双击后停在“正在准备运行环境”**：在下载 Python 和库，视网速 2–8 分钟；
  日志在同目录 `runtime\setup.log`，失败时看最后几行即可定位。
- **公司/学校网络下载不了**：可手动装 Python 3.10 以上（勾选 Add to PATH），
  再执行 `python -m pip install -r requirements.txt`，之后双击 bat 会直接用系统 Python。
- **双击没反应/闪退**：先看 `runtime\setup.log`；或手动执行 `python -m app.server` 看报错。
- **日志里出现 pip 相关报错（`No module named pip`、pip 装不上）**：`get-pip.py`
  必须放在 `runtime\python\` 里、和 `python.exe` 同一目录，并在该目录下运行。手动补装：
  在 cmd 里执行
  ```
  cd /d <本文件夹>\runtime\python
  python.exe get-pip.py
  ```
  成功后重新双击 `启动工作台.bat`（脚本本身也会自动补装，无需手动操作）。
- **想重装环境**：整个删掉 `runtime\` 文件夹，再双击 `启动工作台.bat` 即可。
- **自检**（确认 19 个实验都能算）：在本文件夹执行
  `runtime\python\python.exe -m app.selftest`。
- **端口被占用**：程序会自动从 8765 往后找空闲端口，以命令行窗口打印的地址为准。
- **数据粘贴后结果没变**：点一下「运行计算」（或 `Ctrl+Enter`）。
- **结果与报告差一点**：拟合区间、拐点、取舍点不同都会带来差异，参数卡里可调；
  每个模块的「计算说明」里写了与报告的对照值。
- **想找回原始文件**：输入列底部「原始资料」可直接打开或下载，或点「打开文件夹」。

## 七、关于公式与上下标

- 前端：`_{x}` / `^{x}`（以及 `k_H`、`M^0.78` 这类写法）会渲染成真正的上下标，
  `$...$` / `$$...$$` 里的 LaTeX 子集会渲染成分式、根号等排版。
- 导出的 Word：上下标是 Word 的原生上下标（不是小号字），公式是 **Word 公式对象（OMML）**，
  在 Word / WPS 里可以直接双击编辑，不需要图片或 MathType。
- 想看实际效果：`docx效果图\` 里有 5 张从导出的 .docx 直接翻拍的页面图
  （A1 公式+关系图、B5 分式公式、B5 图表页、A4 上下标、C5 关系图）。
